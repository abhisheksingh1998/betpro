# Betpro

Responsive Next.js marketing site for **Betpro** (powered by Rollwin) — live sports markets, casino tables, and insights.

## Pages

- `/` — Home (hero, live odds, tables, about, edge, CTA, insights preview, FAQ)
- `/blog` — Insights listing
- `/blog/[slug]` — Article detail

## Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- TypeScript

## Develop

```bash
npm install
npm run dev
```

## Deploy

Configured for Vercel. Push to GitHub and import the repo in the Vercel dashboard, or use the Vercel CLI.
